AutoClicker is installed.

Open it from the Applications folder, or the Dock or Desktop if you chose those. If you installed it for yourself only, it's in the Applications folder inside your home folder (in Finder, Go > Home). macOS then asks for two permissions. Allow AutoClicker under System Settings > Privacy & Security:

  • Accessibility, for clicking and Pick location.
  • Input Monitoring, for the F6 hotkey, Esc and recording.

Updating? Each version is a new app to macOS, so the permissions need allowing again. If AutoClicker says one is missing although it looks switched on, select AutoClicker in that list, remove it with the − button, and allow it again.

If macOS says it can't verify the developer when you open it, go to System Settings > Privacy & Security and click Open Anyway.

To uninstall, drag AutoClicker to the Trash from the Applications folder it's in, then drag it off the Dock and delete the Desktop link.
